# Alexa Gagan Portfolio

A static, deploy-ready portfolio for Alexa Gagan, focused on web development, mobile development, full-stack work, and IT support experience.

## Pages

- `index.html` - Home
- `work.html` - Work, projects, and certificate cards
- `skills.html` - Technical skills
- `experience.html` - Experience, education, and certificates
- `contact.html` - Contact links and resume

## Edit Before Deploying

- Add your profile photo as `assets/images/profile-photo.jpg`.
- Add certificate images as:
  - `assets/certificates/database-certificate.jpg`
  - `assets/certificates/python-certificate.jpg`
  - `assets/certificates/networking-certificate.jpg`
- Replace each `Add credential link` URL in `work.html` and `experience.html`.
- Add screenshots or live links for each project when they are ready.
- Replace or expand project descriptions as your capstone and internship work progress.
- Update the resume PDF whenever you revise your resume.
- If you buy a custom domain, add it through your hosting provider.

## Deploy Later

You can deploy this folder with GitHub Pages, Netlify, Vercel, Cloudflare Pages, or any static web host. No build step is required.

For GitHub Pages, upload these files to a repository and enable Pages from the repository settings.
